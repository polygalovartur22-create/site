# Лаборатория слов

Интерактивный урок русского языка для 4 класса: синонимы, антонимы и омонимы.

Урок рассчитан на 23 минуты с вопросами и ответами класса. Сайт предназначен для показа на большом экране с компьютера. Прокрутка страницы переключает объёмные сцены; задания дают обратную связь.

## Использование

Откройте `index.html` или опубликованный сайт в современном браузере. Кнопка «Учителю» открывает отдельное окно со сценарием и таймером. Для вывода на экран используйте кнопку полноэкранного режима. Облегчённый режим уменьшает нагрузку анимации.

Полный сценарий доступен в `teacher-notes.md`.

## Публикация через GitHub Pages

В настройках репозитория откройте **Pages**, выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем сохраните настройки.

## Состав

- `index.html` — автономный сайт со встроенными стилями, кодом и шрифтами.
- `teacher-notes.md` — полный текст выступления учителя.
- `.nojekyll` — публикация без обработки Jekyll.
- `THREE-LICENSE.txt` и `NUNITO-LICENSE.txt` — лицензии встроенных библиотек и шрифтов.

Сайт использует Three.js и шрифт Nunito. Для запуска сборка и установка зависимостей не требуются.
